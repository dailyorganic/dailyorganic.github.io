# dailyorganic.github.io
**The Daily Organic**

Welcome to the repository for [The Daily Organic](https://dailyorganic.github.io)! This project is a daily chemistry puzzle website primarily built for VCE Chemistry 34 chemists to practice Unit 4 organic chemistry nomenclature. 

> **🚧 Status: In Development**
> This project is currently in active development. Features, page layouts, and the daily molecule quizzes are still being built and tested!
